# Club Pádel Costa Brava — Proyecto final DAM

Proyecto académico para gestionar socios, pistas, mantenimiento y reservas de un club de pádel situado en Roses (Girona).

## Aplicaciones previstas

- **Android (Kotlin):** registro de socios invitados, consulta de disponibilidad y gestión de reservas.
- **Escritorio para Windows (Java y JavaFX):** administración de socios, pistas, mantenimiento y reservas.
- **Servidor (Java y Spring Boot):** API REST y reglas de negocio.
- **Base de datos:** PostgreSQL.

## Estado

Planificación inicial. Los requisitos y las decisiones técnicas se concretarán durante el desarrollo.

## Alcance inicial

El prototipo tendrá cuatro pistas, reservas de una hora, horarios según el día y los festivos, y un calendario de mantenimiento semanal y mensual. El trabajo se organizará en GitHub Projects.
